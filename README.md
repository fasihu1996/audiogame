This is a project created for the course "International Media Camp" as a cooperation between students of the Spanish Tecnocampus Mataro and German Technische Hochschule Brandenburg.

## Project purpose
The project contains short audio and video recording made with a 360° camera to create immersive experiences of the two cities Mataró and Brandenburg. These can either be explored through a map functionality or through an interactive guessing game.

In the guessing game, you are provided with a 10 second audio clip of a random location and have to guess, whether the clip belongs to Mataró or Brandenburg. Additionally, you can use the video clip from the same location as a hint if you are unsure. Correct guesses increase the timer while using the hint provides a lower time bonus. Get as many correct as you can before the time runs out!


## Running locally

To launch the project, double click `start-audiogame.bat` and a terminal window should open in a moment.
